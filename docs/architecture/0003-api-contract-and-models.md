# ADR-0003: API contract and DTO strategy

- Status: Accepted
- Date: 2026-08-10
- Context: Backend freezes `/api/v1/` with a documented OpenAPI schema
  (`GET /api/v1/schema/`) and a strict success/error envelope.

## Decision

- The live OpenAPI schema and running backend are the source of truth, NOT
  assumptions.
- DTOs are hand-maintained with `freezed` + `json_serializable` (snake_case
  field mapping), generated by `build_runner`. Enums are plain Dart enums with
  exact backend strings preserved via `api` getters and an `unknown` fallback
  for forward compatibility.
- A full low-quality OpenAPI→Dart generator was NOT adopted; only DTOs needed
  by implemented screens are generated, keeping output clean and reviewable.
- `Page<T>` / `ArchivePage<T>` model the pagination envelope; `ApiErrorMapper`
  converts the backend `{"error":{code,message,details}}` envelope into typed
  `ApiException` surfaced as safe, user-friendly text.

## Consequences

- Regeneration is a single `dart run build_runner build`; drift is checked by
  the real-backend smoke (`tool/smoke.dart`) plus the OpenAPI drift test in the
  backend repo.
